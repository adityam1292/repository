# Images

Put the painting photos and the studio portrait in this folder.

## How to prepare each photo

- Photograph the painting straight on, in daylight, with no glare or frame edges.
- Resize to about 2000 px on the long side.
- Save as JPG or WebP at roughly 300–500 KB.
- Name files in lowercase with hyphens and no spaces, for example `monsoon-field-evening.jpg`.
  File names are case-sensitive once the site is online, so `Painting.JPG` and `painting.jpg` are different files.
